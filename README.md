# Good Harness templates

Harness patterns, templates, eval scripts and raw results for coding agents (Claude Code, Cursor, Codex, GitHub Copilot), published by Good Harness.

Our rule is "measured, not guessed": every pattern carries an evidence grade, and every result we publish comes with its run counts and raw logs so you can rerun it.

## What's here

| Folder | Contents |
| --- | --- |
| `patterns/` | The pattern catalog: one file per harness pattern, with problem, context, trade-offs, solution, per-agent setup, detection check, evidence and grade |

Templates per stack and eval scripts will be added as the series goes on.
